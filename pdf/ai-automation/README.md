# AI 개발 자동화 엔지니어 지원용 PDF 포트폴리오

크로노스튜디오 AI팀 「AI 개발 자동화 엔지니어」 공고에 맞춘 6쪽 A4 포트폴리오입니다.
웹 포트폴리오(`index.html`, 저장소 루트)와는 별개로, 이 폴더만으로 PDF를 다시 만들 수 있습니다.

| 쪽 | 내용 |
|---|---|
| 1 | 프로필, 핵심 숫자, 기술, 연락처 |
| 2 | 지금의 에이전트 환경, 할 수 있는 것, 요즘 하는 것 |
| 3 | Agent SDK 에이전트 팀 4개: 구조, 팀별 안전장치, 실제 실행 로그, 검증 |
| 4 | 직접 만든 도구(문서 MCP, 생성형 AI MCP, 부트스트랩, Skills) |
| 5 | Streams v17: 같은 정보 조건 비교, 난이도 5단계, 정책·가치망 구조(웹 포트폴리오의 `st17-*` 그림) |
| 6 | matail.party, EXAONE 경량화, FAF5 물류 서비스, 프로젝트에서 얻은 것(웹 포트폴리오 「배운 점」·「나의 역량」 요약) |

## 다시 만들기

```bash
node pdf/ai-automation/build.cjs
```

`playwright`와 Chromium이 필요합니다. 결과는 `박원찬_포트폴리오_AI개발자동화.pdf`로 저장되고,
쪽 아래로 넘친 내용이 있으면 경고를 출력합니다. `--png <폴더>`를 붙이면 쪽마다 PNG도 저장합니다.

- 글꼴은 `fonts/`에 함께 들어 있습니다(Pretendard, JetBrains Mono, 모두 OFL).
- 프로젝트 이미지는 저장소의 `assets/img/`를 그대로 씁니다.
- 디자인 색: 차콜 `#3a3a39`, 세이지 `#a3ac84` (`index.html`의 `:root` 변수).
